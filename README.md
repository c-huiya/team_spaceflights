saved_model2.pkl: RandomForest model before optimisation


F1 scores is chosen 
F1 balances the model’s ability to avoid false positives and to avoid false negatives. 
Because F1 ignores true negatives entirely, it focuses solely on the performance of the positive class (repeat buyers). This is ideal when repeat buyers are the smaller class.
